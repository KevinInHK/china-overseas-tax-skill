## 构建

在仓库根运行 `python scripts/build_official.py`。默认生成dist下的版本ZIP，不安装插件、不执行账单、不上传和不提交。只包含明确列出的共享代码、参考和合成例，构建时替换文书参考中的普通版三遍提示，原文件不改；同名产物存在时停止防覆盖。ZIP内含逐文件散列收据，支持检查共享计算脚本未改变。

此目录是构建配置，不是直接安装目录；应使用生成的ZIP。打包检查只涵盖格式、引用、文件范围及ZIP一致性，不是官方服务器审核或运行验证。
