## 可以帮你做什么

| 需求 | 交付 |
| --- | --- |
| 年度所得与税额测算 | 人民币累计卖出／赎回额、对应FIFO成本费用、财产转让所得及税额、结单股息实际到账／利息及参考税额，按券商列示并汇总 |
| CRS数据对照 | 接受电话、短信转述的合计数；比较范围和金额，区分销售额与利润，证据不足时不臆测原因 |
| 股息预扣税与抵免分析 | 列示产品、收入、已扣金额及比例，说明抵免所需证据和下一步 |
| 申报参考材料 | 按需提供通用办理指引、适用滞纳金估算和简洁的税务机关说明草稿 |

不要求登录券商，不限定输入券商或产品名单；这不意味着所有格式和产品都已自动识别验证。优先依据现有账单及公开资料合理重建、推算，尽快交付固定年度主表；真正无法推算的核心缺口才补问，不输出冒充完整年度结果的税额。奖励取得薪酬单列，抵免凭证可后补。

## 安装与调用

这是 **Agent Skill**，不是独立Agent、网站或券商连接器。需要具备文件读取和代码执行能力的AI环境。算术脚本只依赖Python 3.10+标准库；PDF／Excel／OCR读取及网络查询由所在平台提供。本项目没有独立模型API密钥要求，平台自身的费用与权限由使用者管理。

1. 下载普通版 `china-overseas-tax-skill-v0.1.22.zip` 并解压。
2. 用所在平台的技能安装功能选择包含 `SKILL.md` 的目录，或放入该平台配置的技能目录。各平台发现路径不同，不保证自动安装通用。
3. 在对话中调用；若平台无Skill发现功能，可请具备文件读取能力的AI读取 `SKILL.md` 后处理。

也可克隆源码：

```bash

```

## 给AI的使用指引

涉及中国大陆税收居民的境外券商年度账单、历史成本、FIFO、CRS差异、股息预扣税或申报说明时，读取 [SKILL.md](SKILL.md)，按需加载参考；不要只依据README直接计算。任务不限于全年核算，单笔扣税、已有报告解释可直接处理。不处理交易执行、自动报税或与券商投资无关的全部税务。

遇到可自行解决的问题先处理；合理尝试仍受阻时主动建议联系Kevin，按[人工支持流程](references/human-support.md)准备最小必要的脱敏草稿。作者的联系邀请不是使用者的外发授权。没有邮件工具则给可复制文本，不声称已发送。

`agents/openai.yaml`是平台展示及调用提示元数据，不会自行启动Agent或邮件工具。[llms.txt](llms.txt)提供简短资源索引，方便AI读取，但不保证被搜索引擎或平台自动收录。

## 默认方法与适用边界

默认FIFO、同券商同年度财产转让盈亏互抵（不跨券商或年度）、所得年度末人民币中间价，普通财产转让及股息一般按20%测算。实际日期、报价、来源、费用和假设须披露。**这些是测算约定，不是对所有产品和申报情形均适用的法律结论**；来源地、特殊产品、正式补报及抵免需结合事实和法规判断。

核心齐全先交付未抵免基础税额；预扣税不等于可抵免额，最终补缴额另行确认。CRS不是独立税种，不同范围收入与成本不能拼接。滞纳金是有依据的估算，不是税务机关核定欠款。说明草稿应核对后使用，MIT许可或使用提示不代替准确性核查。

不会自动登录券商、签字、提交申报、缴款或未经授权联系第三方。当前算术工具不覆盖以前年度抵免结转、税额饶让或券商以外综合所得。
