# 中国大陆居民境外券商投资税务 Skill

帮助中国大陆税收居民理解券商账单、核算境外投资所得，并准备可复核的税务说明。当前版本：**0.1.18**，实验性辅助工具。

这是一个 **Agent Skill**：由支持技能的 AI 助手读取规则、按需加载参考资料、运行计算脚本。它不是独立运行的 Agent、券商连接器或自动申报服务。`agents/openai.yaml` 仅是技能展示及调用提示元数据，不会启动独立 Agent。

另有独立的 [Codex官方提交候选版](distribution/codex/README.md) 构建配置；它不改变本普通版的邮箱和文书提示设置，也尚未提交或获批。生成方式：`python scripts/build_official.py`。候选版的换环境验证与扩展案例测试暂缓。

## 可以做什么

- 分析年度/月度账单、历史买入及转仓记录，重建 FIFO 成本，列出累计卖出额、成本费用、所得及税额。
- 年度基础测算后，由客户选择 CRS 数据对照、报税及适用滞纳金估算、税局说明草拟；专项请求可以直接进入。
- 解释股息预扣税，列出产品、实际扣税比例和金额，提供抵免证据及办理路径。

不限定上传券商或产品名单，也不要求登录券商。但可以分析不等于所有产品都能自动算出确定税额。AI 负责理解证据及规则，脚本只计算核验后的内部记录。真实成本或关键收入缺失时，不输出冒充完整年度结果的税额。

## 安装与使用

下载 [Releases](https://github.com/tiemuzhenhu123-debug/china-overseas-tax-skill/releases) 中的 ZIP 并解压，或克隆源码：

```bash
git clone https://github.com/tiemuzhenhu123-debug/china-overseas-tax-skill.git
```

用 AI 平台的技能安装功能选择包含 `SKILL.md` 的目录，或将它放入该平台配置的技能目录。具体发现目录取决于平台，不需要修改技能文件路径。若不支持自动发现，可让具备文件读取能力的助手先读取本目录 `SKILL.md` 再处理任务。

例如：

> 用 china-overseas-tax-skill 帮我计算2024年境外券商投资所得税。我会上传年度账单和必要的历史成本记录。

也可以直接要求解释一笔扣税、对照CRS合计数或起草一页说明。

技能本身不需要额外模型 API 密钥。执行平台须提供 AI、文件读取及代码执行能力；扫描件需可用 OCR，规则与汇率核验需网络。PDF/表格读取由执行平台提供，不是算术脚本内置的解析器。

## 默认方法与边界

默认 FIFO、同券商同年度财产转让盈亏互抵（不跨券商或年度）、所得年度末人民币中间价，普通财产转让及股息一般按20%测算。实际日期、报价、来源、费用和假设须向客户披露。**这些是测算约定，不是对所有产品和申报情形均适用的法律结论**；来源地、特殊产品、正式补报及抵免需结合事实和法规判断。

核心齐全先交付未抵免基础税额，抵免资料可以后补。预扣税不等于可抵免额；最终补缴额另行确认。CRS不是独立税种，不同范围收入与成本不能拼接。滞纳金是有明确依据的估算，不是税务机关核定欠款。

文书默认简洁、来源明确，抬头为“致：主管税务机关”；草稿回复末尾提供使用提示。提示与MIT许可不替代准确性核查，也不意味着运营方当然免责。收费受托服务还需审查实际适用的涉税专业服务管理要求。

不会自动登录券商、提交申报、签字、缴款或联系第三方。当前算术工具不覆盖以前年度抵免结转、税额饶让或券商以外的综合所得。

## 计算工具与测试

两个脚本只依赖 Python 3.10+ 标准库。由AI理解账单并形成核验后的输入，客户不需要填写JSON。

```bash
python -m unittest discover -s tests -v
python scripts/calculate.py examples/synthetic-ledger.json --out work/example-result.json
python scripts/late_fees.py examples/synthetic-late-fees.json
```

合成例中的日期、汇率和金额仅用于演示，不得作为真实事实。字段及状态见 [内部记录与工具](references/records.md)。测试验证算术及输入边界，不证明所有券商格式、法律判断或真实会话表现均已验证。
